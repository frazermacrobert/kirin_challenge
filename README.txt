Memory Walk — Kirin (p5.js prototype)
====================================

Files:
- index.html       -> main page
- style.css        -> styles for header, controls, popover, etc.
- sketch.js        -> p5.js sketch that draws the timeline, orb, milestones and pixelation
- assets/kirin_badge.svg -> placeholder Kirin badge (replace with your real design)

How to use:
1. Unzip the project and upload the files to a new GitHub repo (root files).
2. In the GitHub repo settings, enable GitHub Pages from the main branch (root).
3. Visit the provided GitHub Pages URL (https://yourusername.github.io/your-repo/) to see the live prototype.
